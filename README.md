# trmnlear-case - an trmnl 7.5" enclosure with ears added extension for the cuter look!
The normal enclosure is too basic for me, I love animal so I have decided to creates an enclosure to match my style. It currently have 5 unique ears pieces

### Including:
- Bunny Ears
- Fox Ears
- Giraffe Ears
- Deer Antlers
- Bear ears
